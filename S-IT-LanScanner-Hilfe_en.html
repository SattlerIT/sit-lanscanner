1. Quick start

First scan in 3 steps

  1. Start the program – double-click sit-lsc-start.exe. Confirm administrator rights if asked (recommended for the ARP scan).
  2. Choose a network – select the desired network in the drop-down list at the top left (it is detected automatically).
  3. Start the scan – click ▶ Start scan. After the scan, all devices found appear in the list.
Tip: Turn on the port scan in the settings to detect services and the operating system more precisely. The scan then takes longer but provides considerably more information.

3. Running a scan

Which range should I scan?

The network field at the top left determines which addresses are checked. It is a drop-down list and an input field: the automatically detected networks are offered for selection – but you can also simply type into it.

NotationExampleMeaning
From–to 192.168.0.1-192.168.0.50 All addresses from the first to the last – the simplest notation
Short form 192.168.0.1-50 The same, only the last address block is given
Whole network 192.168.0.0/24 Technical notation (CIDR) for a complete network
Single device 192.168.0.7 Check only this one address

A smaller range is considerably faster: instead of 254 addresses, only the ones you are really interested in are checked. For very large ranges the program asks first, so that a scan does not accidentally run for hours.

If an entry is not accepted: the program explains in plain words what is wrong – for example if the second address comes before the first. Check the dots and the hyphen; spaces do not matter.

Scan intensity

The scan intensity determines how aggressively the network is queried. It can be set under ⚙ Config → Scan intensity:

ModeMethodRecommendation
Safe Ping only (ICMP) For sensitive networks, older printers or if devices were no longer reachable after the scan
Standard Ping + ARP scan For home networks – finds more devices than safe mode
Intensive Ping + ARP scan in two passes For professional environments. May briefly interrupt the connection on some routers
Note on printers: older network printers (e.g. Brother HL models) may react to aggressive ARP floods with a connection failure. Use the scan intensity Safe in such networks.

Follow-up search for missing devices

Some devices do not answer the first time, for example in power-saving mode or with a weak wireless signal, and some never answer ping at all. The follow-up search therefore asks again in a targeted way – only at addresses that have not answered yet. Set it under ⚙ Config → Follow-up search for missing devices:

  • Off – no follow-up search.
  • Known addresses (default) – addresses where a device was found in earlier scans are asked a second time with more patience. Devices without an open port get a second attempt on their web interface. Takes a few seconds.
  • All silent addresses – in addition, typical ports are checked on all addresses without an answer. This also reveals devices that do not answer ping, for example voice assistants or Windows PCs with a closed firewall. Takes noticeably longer.

Port scan

The optional port scan (can be turned on in the settings) checks well-known service ports on each device and considerably improves operating system detection. It makes the scan take longer but provides much more information – especially which services a device offers (web interface, SSH, RDP etc.).

📶 Connection Quality

If telephony or video stutters or a device is only reachable at times, this measurement shows whether the problem lies in your own network or beyond it. Open it via the 📶 Connection Quality button in the LAN Scanner tab, by right-clicking a device or in the device details.

  1. Choose the target – Internet (8.8.8.8), the gateway or a device from the last scan.
  2. Choose the duration – 30, 60 or 120 seconds.
  3. ▶ Start measurement – the target and the gateway are measured at the same time.

For both paths, the result gives the packet loss, the response time and its jitter, and assesses them in two parts: the connection (based on packet loss) and the suitability for telephony and video (based on response time and jitter). If the values to the gateway are good and those to the target are poor, the cause lies beyond the router. 📋 Copy result lets you pass it on.

ℹ Cameras and similar devices: many devices answer ping only as a side task. A high jitter there often reflects the load on the device and not the quality of the network. For such devices, the packet loss is what counts.

Scan options

  • Port scan – finds services and improves OS detection (slower)
  • ARP scan – finds more devices through ARP broadcasts
  • OS detection – analyses TTL, host name and manufacturer

Scan intensity

Safe / Standard / Intensive – see section 3.

Language

Under ⚙ Config → Sprache / Language you choose the language of the program interface: German, English, Dutch, Spanish, French, Italian, Polish, Croatian or Czech. The new language takes effect after the program is restarted; the program offers the restart when you save. The help then also opens in the selected language.

Appearance

  • Subtle – calm pastel tones, for professional use
  • High contrast – stronger colours, easier to tell apart
  • 🌙 Dark mode – dark backgrounds and light text in all program windows, more comfortable for long work at the screen. The rows of the device list keep their colour by device type, only darker. Takes effect after a restart, which the program offers when saving. Windows message boxes and the reports in the browser remain light.
  • Font size – Small (8 pt), Normal (9 pt), Large (11 pt). “Large” is recommended for 4K screens or high resolutions

HTML report

If “Open automatically after scan” is turned on for the HTML report, the scan report opens automatically in the default browser after each scan. This can be turned off here.

Log folder

Here you can set where scan logs and HTML reports are saved. Default: Logs next to sit-lsc-start.exe

Wait time for network drives

Applies to the LAN continuous test with a target on the network (\\NAS\share or a mapped network drive such as U:). A NAS whose hard disks are in standby needs a few seconds after the first request until the share is reachable. The program therefore retries every 3 seconds up to the set time and only then reports that the target is not reachable. You can choose 0, 30, 60 or 120 seconds; the default is 60.

Display size / scaling

Scales the entire interface. Available levels are 90 / 100 / 125 / 150 / 175 / 200 / 250 / 300 %. The selected level alone determines the size – the Windows scaling is then not applied on top. The 90 % level is compact and gives more room for tables. Which level suits which purpose is explained by the ⓘ button next to the heading. A change takes effect after a restart, which is offered when saving.

ℹ Relation to the Windows scaling: as long as a level is selected here, it determines the display size – regardless of the Windows setting. If no level is selected, the program follows the Windows scaling.

Program start

The “🛡 Start as administrator” check box (default on) requests administrator rights right at program start. The scanner needs them for network repair, the ARP cache and the firewall tab. Windows then asks for confirmation at start (User Account Control, UAC). If you deliberately work without admin rights, untick the box – the prompt is then skipped, and the functions mentioned report by themselves when they need rights. At the bottom left of the status bar, a permanent indicator shows the actual state: 🛡 Admin or 🛡 no admin.

Window

With “🗖 Remember window size” the program remembers the size and position of the main window on exit – including the monitor it was on – and whether it was maximized. At the next start it opens exactly like that again. If that monitor is no longer connected, the window opens on the main screen. The saved size applies per scaling level: after changing the scaling, the window starts once in standard size and then remembers the size anew – so size and space requirements always match.

ℹ Config window: at high scaling, the settings window becomes larger than the screen. It can therefore be scrolled in both directions (mouse wheel vertically, Shift+mouse wheel horizontally); the Save and Cancel buttons always remain visible at the bottom.

Diagnostics

The “🔧 Show DIAG tools” check box shows the 🔧 DIAG button at the top of the header. By default it is off – the diagnostics are not needed for normal use. More in section 11.

6. Own device information (S-IT-Custom.ini)

Not every device can be classified reliably by automatic means – a new device is still missing from the manufacturer database, a camera identifies itself like a Linux computer, or with several identical devices you want to see which one is where. For this you enter your own information. It is stored in the file S-IT-Custom.ini and applies permanently.

Important: your own entries always take precedence over automatic detection. S-IT-Custom.ini is never overwritten by OUI updates.

Method 1: right-click → “Label device …”

This is the easiest way:

  1. Run a scan
  2. Right-click the device in the list
  3. Choose “✏ Label device …”
  4. Fill in the desired fields:
    • Device name – applies to this device, e.g. location or room (“Camera yard”, “Printer office 2”)
    • Manufacturer – applies to all devices with the same MAC prefix
    • Device type – choose from the list or enter freely
  5. Specify what the device type applies to:
    • this device only – via the MAC address (without a MAC via the IP address)
    • all devices with this MAC prefix – e.g. all cameras of one manufacturer
    • all devices with this name part – e.g. all devices whose host name contains “SmartPlug”
  6. Save – the entry appears in the list immediately.

An empty field or “– determine automatically –” removes your own entry again; the automatic classification then applies.

Method 2: OUI management window

Via 🔄 OUI Update → tab “✏ Own assignments” you see all entries in one overview and can add, change and delete them. The sub-tabs:

  • OUI → manufacturer – MAC prefix (6 hex characters) → manufacturer name
  • MAC → name – MAC address → own device name
  • MAC → type – MAC address → device type (a single device)
  • IP → type – IP address → device type (device without a MAC address)
  • Host name → type – name part → device type (all devices with this name part)
  • MAC prefix → type – MAC prefix → device type (all devices of one manufacturer)

File format of S-IT-Custom.ini

The file is located in the Config folder next to sit-lsc-start.exe and can also be edited with a text editor. MAC addresses are written with hyphens. Section names and device types are written in German, as the program stores them (e.g. Kamera = camera); the program shows the device types in the set language.

; S-IT-Custom.ini – own priority assignments
; NOT overwritten by the OUI update.

[OUI]
; MAC prefix (6 hex) = manufacturer
CC7314 = Cubot (Android)

[Gerätename]
; MAC address = own device name
E0-09-BF-1F-6B-FB = Camera yard

[Gerätetyp]
; MAC address = device type (this device)
E0-09-BF-1F-6B-FB = Kamera

[IP]
; IP address = device type (device without MAC)
192.168.0.38 = Smartboard

[Hostname]
; name part = device type (all devices with this name part)

; MAC prefix (6 hex) = device type (all devices of one manufacturer)
E009BF = Kamera
Order for the device type: single device (MAC or IP) > name part > MAC prefix > automatic classification
ℹ Older entries: up to version 4.0, the sections [IP] and [Hostname] set the operating system. They now determine the device type; existing entries remain valid and appear in the “Device type” column.

7. Tab 2: Internet Reachability

At the top of the tab you choose one of four checks:

CardPurpose
🌐 Internet reachability Checks whether this PC can reach the Internet: DNS, routing, TCP 443, HTTPS, IPv6 and browser.
🔗 LAN connection path Checks the path from the PC via the gateway to a target in your own network, e.g. via powerline to the NAS or to the router.
📶 Speed test Measures download, upload and ping of the Internet connection.
🏷 Domain lookup Shows with which provider the DNS records of a domain are managed, who receives its e-mail and where the website is hosted.

🏷 Domain lookup

Typical occasion: a service provider is to change a record of the company domain, for example for a new mail server or a verification for a cloud service, and nobody knows any more where the domain is managed. The domain lookup shows it with one query. No administrator rights are needed, but an Internet connection is.

Operation

  1. Choose the 🏷 Domain lookup card.
  2. Enter the domain, e.g. company.com. A web address (https://www.company.com/contact) or an e-mail address (info@company.com) also works, as do domains with special characters such as umlauts.
  3. Click ▶ Check or press Enter.

If an entered sub-address such as shop.company.com has no name servers of its own, the program checks the parent domain company.com and says so in the line above the result.

Results

LineMeaning
Name servers The servers responsible for the domain in the DNS.
DNS managed by The provider of these name servers. This is where the DNS records of the domain are changed.
Mail servers The servers that receive e-mail for the domain, with their priority: the server with the lower number is tried first. If it says “none entered”, the domain does not receive e-mail.
E-mail with The provider of the mail server. If it says “filter service”, a spam and virus filter receives the e-mail and forwards it to the actual mailbox.
Web server The address of the website (www.company.com, otherwise company.com) and its IP addresses.
Website with The provider hosting the website.

Below each provider, grey text shows the server's address, its host name, the name of its network and its address range.

Where the information comes from

  • Provider: the program knows the name servers and mail servers of the common providers, e.g. IONOS, Strato, Cloudflare, Microsoft 365 and Google Workspace. If a server is not listed there, it names the operator of its network according to the responsible registry, e.g. RIPE for Europe or ARIN for North America. The brackets then say “network operator according to RIPE”.
  • Country: the country in which the server's network is registered with the registry. This is usually the location of the data centre, but not always: large companies often register their networks to their headquarters.
  • “not assigned”: the server is not on the list, and the registry was not reachable or named no operator.
Name servers and registration: where the DNS records are managed is usually also the provider with whom the domain is registered. With DNS services such as Cloudflare, the domain can be registered with another provider.
Tip: 📋 Copy result puts the result on the clipboard as text with date and time, e.g. for an e-mail to the customer or the service provider.

8. Tab 4: LAN Performance & Wi-Fi

LAN speed test

Measures the actual write and read speed to a network share – without server software on the other side.

Requirements

  • A reachable network share (e.g. \\NAS-name\Data) or a mapped network drive (e.g. U:)
  • Write permission on the share

If the NAS is asleep, the program waits up to the set wait time for network drives (section 5) before reporting that the target is not reachable. If Windows lists a network drive as “unavailable” (red cross in Explorer), the program reconnects it, as Explorer does when you click it.

Important: the server name alone is not enough.
\\NAS-name only shows the list of shares in Explorer – no file can be created there, so the test fails. The share itself must be specified, e.g. \\NAS-name\Data. The easiest way is to select it via 📂, then the path is always correct. The ⓘ button next to the input field explains this as well.

A local folder (e.g. C:\Temp) is also allowed as a target – for comparison, it shows how fast the PC is without the network.

Operation

  1. Enter the target or select it via 📂. The path is checked before the start; if something is wrong, a message explains exactly what is missing.
  2. Choose the chunk size (1–64 MB per measurement cycle)
  3. ▶ Start continuous test – the test runs continuously and updates the live chart
  4. ⏹ Stop – ends the test

If another tab is opened during the test, the program asks whether the test should be stopped. With No, the LAN Performance & Wi-Fi tab stays open and the test continues. When the program is closed, the test is stopped and the test file is deleted.

Results

  • Blue line – write speed
  • Green line – read speed
  • The tiles always show the current measured value
  • The measurement log lists every single cycle
Local drives: with local drives (e.g. C:\, D:\), the measured values can be considerably distorted by the Windows file system cache – the cache reports “done” before the data is really on the disk. Values of several thousand Mbit/s on a normal HDD are therefore not a realistic result. For meaningful measurements always use a network path (UNC path such as \\Server\Share or a network drive).
Typical guide values:
Gigabit LAN: 400–900 Mbit/s  |  100 Mbit LAN: 60–90 Mbit/s  |  Wi-Fi (802.11ac): 150–400 Mbit/s
Smaller chunk sizes (1–4 MB) show more fluctuation because overhead and latency carry more weight. For stable values, 16–64 MB are recommended.

Wi-Fi and LAN tile

On the right of the tab, the Wi-Fi tile and the LAN tile stand side by side, with the IPv4 address and gateway below. Both tiles are built the same way: the status at the top, below it the adapter with the name under which it also appears in Device Manager.

With an existing connection, the Wi-Fi tile shows:

  • Network name and connection status
  • Signal strength as a coloured bar (green good, yellow fair, red weak)
  • Channel, frequency band and Wi-Fi standard (e.g. Wi-Fi 6)
  • ⬆ Link rate – the rate that Windows reports for the connection
  • ⬇ Receive rate – only during the LAN continuous test (see below)

If there is no connection, the tile states the reason: Adapter disabled (switched off in Device Manager or in Network Connections), Not connected or No Wi-Fi adapter. The LAN tile additionally distinguishes No cable connected.

ℹ Receive rate only during the continuous test: the receive rate reported by Windows is only meaningful while data is flowing. Without traffic it drops to low values even though the connection is good. The tile therefore only shows it while the LAN continuous test is running – then the receive rate and the measured write and read rates can be compared directly. The tile is updated immediately when the test starts and stops.
ℹ Location access: Windows 11 only provides signal strength, channel and Wi-Fi standard if desktop apps may access the location. Without this permission, the tile shows a note with the “→ Open location settings” button. The program then takes the network name from the Windows network list and points out that it may differ from the Wi-Fi name (e.g. “Home network 2”).
ℹ Updating: both tiles are updated every 10 seconds; a switch from LAN to Wi-Fi or a USB Wi-Fi stick plugged in later is detected without a restart. 🔄 Refresh updates them immediately.

ButtonFunction

Moving to a new PC

  1. On the old PC: ④ Back up profiles and choose a USB stick as the target.
  2. On the new PC: start the LanScanner, Wi-Fi Profiles tab, ⑤ Import profiles and choose the WLAN-Profile_… folder on the stick.

Top right: your connection compared with the Wi-Fi standards

The chart shows as grey bars the typical link rates of PCs and notebooks for Wi-Fi 4 (802.11n) to Wi-Fi 7 (802.11be), each with its frequency band. If it is at the lower end of its standard, it is worth looking at the distance to the router, the channel and the band.

ℹ Link rate and data throughput: the link rate is the gross rate of the radio connection. In practice, about half to two thirds of it is actually transferred. The real throughput is measured by the LAN continuous test in tab 4.

Bottom right: Wi-Fi networks in range

The table lists the Wi-Fi networks the adapter currently receives, with signal, network name, band and channel, standard, encryption and whether the network is saved on this PC. For saved networks, the “Show password” link shows the password directly. When the tab is opened for the first time, the surroundings are scanned once; “Scan for networks” searches again.

ℹ Location access: Windows 11 only provides the Wi-Fi networks in range, signal strength and Wi-Fi standard if desktop apps may access the location. Without this permission, a note with the “→ Open location settings” button appears in place of the table.

Wi-Fi report

Button ⑥ summarises the status in a colourful HTML file – suitable for passing on, for the customer file or for a before-and-after comparison:

  • Wi-Fi connection with adapter, signal, band, channel and link rate
  • LAN connection
  • IPv4 address and gateway
  • Classification of your own connection among the Wi-Fi standards
  • Wi-Fi networks in range
  • Saved profiles

Passwords are not included in the report. It is saved in the log folder as WLAN-Bericht_<PC name>_<date>.html and opened in the browser.

10. Tab 6: Firewall & Ports

This tab deals with two separate cases, which is why it is divided into two columns. Both access the same Windows firewall but look at it from opposite directions:

  • Left – “Reach a device on the network”: another device in the LAN (NAS, printer, FritzBox USB) cannot be reached from this PC.
  • Right – “Port on this PC”: a program on this PC needs a specific port that others on the network access (inventory management, POS system, database, remote maintenance).

Below both columns, the shared rule list spans the full width; it shows the entries from both columns.

⚠ Admin rights required: reading and setting firewall rules only works with administrator rights. The easiest way is to leave “Start as administrator” turned on (see section 5, on by default). If the program runs without admin rights, the tab reports this when checking or adding.

Left column: reach a device on the network

Use this if a device is visible in the scan (or should be) but cannot be reached – no ping, no file sharing. Often the Windows firewall of this PC blocks the connection. This column is taken over from the stand-alone tool S-IT-FWModify.

  1. Enter the IP address or subnet – a single address (e.g. 192.168.178.60) or a whole subnet (192.168.178.0/24). Recently used targets are available in the drop-down field.
  2. Choose the scope of the exception:
    • All ports – for a single, known device
    • File sharing only – TCP 445, 139 and UDP 137, 138 (SMB)
    • File sharing + web interface – additionally TCP 5000, 5001 (e.g. for NAS interfaces)
  3. Check – the result appears in five lines (see below).
  4. Add exception – creates the matching firewall exception.

The five check lines:

  • Device responds to ping – basic reachability on the network
  • Open ports on the target – what does the device offer, is file sharing among it?
  • Firewall base setting – can an exception have any effect here at all?
  • Network profile of this PC – Private = sharing possible, Public = everything blocked
  • S-IT rule for this target – is there already an exception set by this tool?

Right column: port on this PC

Use this the other way round, if a program runs on this PC and must open a specific port so that other computers on the network can access it – for example inventory management, a POS system or a database that offers its service on a fixed port. The rule applies inbound and only from the local network.

  1. Choose a template (optional) – common cases are stored and fill in port, protocol and description automatically: SQL Server (1433), MySQL/MariaDB (3306), PostgreSQL (5432), Remote Desktop (3389), VNC (5900), HTTP (80), HTTPS (443), HTTP alternative (8080), HTTPS alternative (8443). With “– custom entry –” you enter any port yourself.
  2. Port (or range) and protocol – a single number (e.g. 1433) or a range (e.g. 5000-5010, at most 200 ports), plus TCP or UDP.
  3. Description – a name under which the rule can be found again later in the list (e.g. “inventory management, POS system”).
  4. Check – the result appears in three lines (see below).
  5. Open port – creates an inbound rule for the local subnet.

The three check lines:

  • Program listens on the port – without a listening program, no firewall rule has any effect. If the program only listens on 127.0.0.1, it cannot be reached from the network even with a rule – then the program itself must be bound to the LAN address.
  • Inbound firewall rule – existing rules for this port, including third-party ones (e.g. from the installer of the business application). Rules that only apply to a single other program or another Windows service are shown as having no effect.
  • Firewall profile of this PC – the rule applies to the private profile; in the “Public” profile Windows blocks anyway.

The result (both columns)

Each check line shows a result: green OK, yellow a note, red a problem. Where useful, the line offers a small button on the right for a direct fix – for example switching the network profile to “private” (so that sharing is allowed at all) or opening the port right away. The detailed explanation for each line appears when you hold the mouse over it.

The shared rule list

All exceptions the program creates – from both columns – have their own name (prefix S-IT-FW-) and appear in the list below. Each entry usually creates several firewall rules (per direction and protocol). The buttons below remove selected or all S-IT rules again.

Your other firewall rules remain untouched. The program only sees and changes its own rules with the prefix S-IT-FW-. Third-party rules from Windows or other software are neither shown nor deleted.
ℹ Tidying up made easy: if an exception or an opened port was only set for testing, remove it later with one click via the rule list – this keeps the firewall clean.

11. Diagnostics (DIAG) – for testers

This section is aimed at testers and anyone who wants to report a detection problem. None of it is needed for normal use.

What for?

Windows provides network information through several channels. Which of them responds differs from computer to computer – depending on the Windows edition, drivers and company policies. If the program shows wrong values on a device, the display does not reveal why. The diagnostics therefore query each channel individually and record what it answered – even if it did not answer at all.

Switching on

⚙ Config → Diagnostics → “🔧 Show DIAG tools”. The 🔧 DIAG button then appears at the top of the header. No restart needed. Removing the tick hides it again.

The three tools

ButtonFunction
▶ Create DIAG Creates exactly one file in the Diag folder next to sit-lsc-start.exe. Nothing happens by itself – only on click.
🔍 Show plain text Shows the content in readable form – exactly what would be sent. Can also be saved as plain text on request. The content has the same structure in all language versions and is not translated.
📁 Open folder Opens the storage folder in Explorer.

What does it contain?

  • The raw responses of all queries (PowerShell, wmic, registry, netsh, ipconfig), including the Wi-Fi networks in range
  • How the LAN and Wi-Fi tiles display these responses
  • Windows and program version, scaling, admin rights
  • What the program made of the responses
  • After a network scan, additionally the device list of that scan: for each device the name, IP address, manufacturer, open ports and the program's classification with the reason

No passwords, no credentials. MAC addresses are shortened: the manufacturer part remains – detection needs it – and the device-specific part is replaced by XX (54:E1:AD:XX:XX:XX).

Why is the file not readable?
It is obfuscated so that it is not accidentally read along or taken apart by a mail filter. This is expressly not encryption and is not meant to be. With 🔍 Show plain text you can see what it contains at any time.

Sending it in

Voluntarily and only for a detection problem: send the file to tool-entwicklung@sattler-it.de. A sentence about what was displayed incorrectly is helpful.

12. Files, updates and backup

Structure of the program folder

Everything you need yourself is at the top, next to the start program. The subfolder sit-lsc_program contains only the program itself and does not need to be opened:

S-IT-LanScanner\
  sit-lsc-start.exe   ← starts the program
  Config\   ← settings, own entries, manufacturer database
  Logs\   ← scan logs, reports and other logs
  Diag\   ← diagnostic files
  Help\   ← help, ChangeLog, disclaimer and licence
  sit-lsc_program\   ← the program

The program creates the Config, Logs and Diag folders itself when needed.

Short checklist – what to take along?
When changing PCs or reinstalling, back up these folders next to sit-lsc-start.exe:
  • Config\ – settings, own entries for devices and the manufacturer database
  • Logs\ – the complete folder, if old scans, logs and Wi-Fi reports are to be kept
After copying, start the program – all settings, assignments and previous scan results are available again immediately.

Performing an update

  1. Download and unpack the new version
  2. Important: copy the Config folder from the old program folder into the new one
  3. Start the program via sit-lsc-start.exe
  4. All settings and own information are available again
Earlier versions did not yet have a Config folder. In that case, copy the files S-IT-LanScanner.ini and S-IT-Custom.ini into the new program folder next to sit-lsc-start.exe. At the first start, the program moves them once into the Config folder, as well as logs and diagnostic files that are still in the sit-lsc_program folder. Nothing is overwritten in the process. What was moved is listed in the file Ordnerumzug.log in the log folder.

Reinstallation / changing PCs

Recommended procedure:

  1. Copy the backed-up Config folder into the new program folder next to sit-lsc-start.exe
  2. Also copy the backed-up Logs\ folder there (or into the configured log folder)
  3. Start the program – all settings, assignments and previous scans are available in the log manager immediately
  4. Optional: run the OUI update to load the latest manufacturer database
If no files are backed up: S-IT-LanScanner.ini and S-IT-Custom.ini are recreated automatically with default values at the first start. Own device information must then be entered again.
Taking Wi-Fi networks along: the saved Wi-Fi networks of the old PC can be backed up in the Wi-Fi Profiles tab and imported on the new PC (section 9).

Updating the OUI database

Via 🔄 OUI Update → tab “OUI database update” → “▶ Update OUI database” the program downloads the complete IEEE vendor lists (MA-L, MA-M and MA-S) and saves them in S-IT-OUI.ini. An Internet connection is required. Progress and result appear in the same window. The database is then reloaded at once – no restart needed.

If one of the lists cannot be downloaded, a message appears and the existing S-IT-OUI.ini remains unchanged.

The file S-IT-Custom.ini with your own information is never changed or overwritten by the OUI update.

13. Frequently asked questions (FAQ)

A device is not found

Possible causes:

  • The device is switched off or in power-saving mode
  • The device does not answer ICMP ping (firewall) → turning on the port scan helps
  • The device is in another network segment
  • Choose the “Safe” scan intensity and scan again

A device is classified wrongly or not at all

Right-click the device → “✏ Label device …” → choose or enter the device type → Save. The entry appears in the list immediately and applies permanently (section 6).

Why is the “Device type” column empty for some devices?

The clues were not enough for a clear classification. The program then deliberately leaves the field empty instead of guessing. A port scan that is turned on often provides enough additional clues; otherwise your own entry via “Label device …” helps.

My printer was no longer reachable after the scan

Set the scan intensity to “Safe” in the settings. This level does without ARP floods and port scans on printer ports, which can overload older firmware versions.

The antivirus program reports a threat

Because the LAN Scanner actively scans the network, some antivirus programs wrongly classify it as suspicious (false positive). The program contains no malware whatsoever. Solution: add the program file and the folder to the exception list / whitelist of the antivirus program.

The LAN speed test shows “No write access”

The share is probably connected read-only or the credentials are not sufficient. Check your write permissions on the share.

The test says “Share missing”

Only the server name was specified, e.g. \\NAS-name. No file can be created there – the share itself is needed: \\NAS-name\Data. See section 8.

The Wi-Fi tile shows “Connected” but no signal strength and no channel

This is almost always the location lock of Windows 11 and not a fault of the program: Windows only provides signal strength, channel and Wi-Fi standard if desktop apps may access the location. The same applies to the Wi-Fi networks in range in the Wi-Fi Profiles tab. The adapter itself is still detected correctly.

Remedy: click “→ Open location settings” in the tile (or Settings → Privacy & security → Location). Turn on the location services there and, further down, allow location access for desktop apps. Then click 🔄 Refresh in the tile.

The network name in the Wi-Fi tile differs from the Wi-Fi name

Without location access, the program takes the name from the Windows network list; the tile says so. Windows may create numbered entries there for the same Wi-Fi, for example “Home network 2”, if the PC has connected several times or with different adapters. With location access, the tile shows the actual Wi-Fi name.

Why does the Wi-Fi tile show no receive rate?

The receive rate only appears while the LAN continuous test is running. Without traffic, Windows reports low values for it that have nothing to do with the quality of the connection. The link rate (⬆), on the other hand, is always shown.

The Wi-Fi tile reports “Adapter disabled”

The Wi-Fi adapter is switched off in Device Manager or under Network Connections. After switching it on, the program detects it within 10 seconds at the latest; with 🔄 Refresh immediately. A USB Wi-Fi stick plugged in later is also detected automatically.

The speed says “unknown”

Then none of the queries could provide a speed – typical for a disabled adapter, for which Windows reports no rate. In this case the program deliberately shows “unknown” instead of an estimated number: a value that nobody has measured has no place in a diagnostic tool. The adapter name is still shown.

The program looks too small on my UHD/4K monitor

Open ⚙ Config and choose a higher value under “Display size / scaling” in the right column. The program restarts automatically after saving.

Recommendation for UHD/4K: the program scaling alone determines the size – you do not have to change the Windows scaling for it. Start with 150 %; this gives a well readable display on most UHD monitors. If it is still too small or too large, choose the next level until text and elements are optimally readable for you.

Available scaling levels in the program: 90 / 100 / 125 / 150 / 175 / 200 / 250 / 300 %.

Where can I find the disclaimer?

In the file Lizenz-Disclaimer.txt in the Help folder and on the project page. In short: the results are non-binding indications and a snapshot – they do not replace a professional security audit.

I switched SMB1 – why does it still show the old state?

SMB1 is a Windows feature, not a simple switch: Windows installs the files when enabling it and removes them when disabling it. The change only takes effect after a restart – until then the check still reports the previous state. The program does not restart the computer by itself; it only points this out. Restart Windows yourself when convenient.

Why are there three SMB1 lines?

Because SMB1 consists of several independent parts. If you only see one line, you can easily get a wrong picture of your own computer:

LinePurpose
SMB1 client So that this PC can access old devices – for example an older NAS or a network printer that does not support SMB2/3. This is the most common case.
SMB1 server So that old devices can access the shares of this PC – for example a copier that stores scans in a shared folder. This side is the more dangerous one and should only be on as long as the old device needs it.
Keep SMB1 permanently Windows removes SMB1 again by itself if it has not been used for 15 days. This line switches the automatic removal off. Useful if the business has longer breaks – after two weeks of company holidays, SMB1 would otherwise suddenly be gone and the scanner would stand still.

The Keep SMB1 permanently line only becomes relevant if the client or server is actually active. If SMB1 is completely off, it is shown in grey and needs no attention.

The SMB1 server says “Feature present, but protocol off” – what does that mean?

The server side has two levels: the installed Windows feature and the protocol switch in the SMB server. After switching on, at first only the feature is there – the switch can only be set after the restart. This is exactly what the “→ Complete” button is for: it sets the second switch and takes effect immediately, without another restart. If the SMB1 server is not needed after all, switch it off completely instead.

Why is the button on a green line grey?

A button on a green line always leads back to the less secure state – for example “← Enable” for a switched-off SMB1 server. Such reset buttons are deliberately kept subdued so that they do not invite accidental clicks. They work quite normally.

Where are the logs saved?

Default: Logs\ next to sit-lsc-start.exe. The folder can be changed under ⚙ Config → Log folder.

Can I use the tool on a USB stick?

Yes, the tool is portable. Copy the complete program folder – that is sit-lsc-start.exe together with the sit-lsc_program folder and the other folders – to the USB stick. The INI files are saved in the Config folder.

Where can I find the Wi-Fi reports and the log of the Wi-Fi profiles?

Both are located in the log folder, by default Logs\ next to sit-lsc-start.exe. In addition, the Wi-Fi report opens in the browser right after it is created.

The domain lookup shows no country

Country, network and address range come from the registry (e.g. RIPE). If it is not reachable, for example because a firewall or proxy blocks the query, the program only shows the provider from the built-in list.

In the domain lookup the country does not match the provider

The country is the country in which the server's network is registered. Large companies often register their networks to their headquarters, even if the server is in a data centre in another country. See section 7.
